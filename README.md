This directory hosts first-party integration packages for the Lumen chain.

- `npm/`: JavaScript/TypeScript packages, including the main SDK and the domain resolver.
- `utils/`: Shared build artifacts/tooling reused across integrations (e.g., the Dilithium3 WASM builder).
- Future folders will cover native mobile bindings, gateway agents, and other client SDKs.

Each integration keeps its own README and build tooling; shared guidance and release notes will be collected here once multiple packages are available.
